✦ Sobre

A Kyara High-Tech é um bot modular para WhatsApp desenvolvido em Node.js.

Projetada para concentrar diferentes sistemas em uma única plataforma, mantendo os componentes organizados e independentes.

IA
├── Assistente
├── Contexto
├── Persona
└── Conhecimento

MÍDIA
├── Áudio
├── Vídeo
├── Música
└── Stickers

SISTEMAS
├── Grupos
├── Jogos
├── Economia
├── Leveling
└── Administração
