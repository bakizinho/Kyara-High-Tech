## ✨ Sobre a KYARA

A **KYARA High-Tech v1** é um bot para WhatsApp desenvolvido em **Node.js**, com foco em automação, downloads, diversão, administração de grupos e sistemas interativos.

O projeto foi desenvolvido para funcionar diretamente no **Android usando Termux**, sem depender obrigatoriamente de hospedagens pagas.

### 🚀 Principais recursos

- 📥 Downloads de mídias.
- 🎵 Pesquisa e download de músicas.
- 🎬 Download de vídeos.
- ▶️ Integração com comandos do YouTube.
- 🎞️ Suporte a TikTok.
- 📸 Suporte a Instagram.
- 📘 Suporte a Facebook.
- 🦋 Suporte a Kwai.
- 🐦 Suporte a Twitter/X.
- 📌 Suporte a Pinterest.
- 🎮 Sistemas de diversão e RPG.
- ⭐ Sistema de níveis e XP.
- 🧩 Arquitetura modular.
- 🛠️ Ferramentas administrativas.
- 📱 Menus interativos para WhatsApp.
- 🔐 Recursos de controle para grupos.

## ⚙️ Requisitos

Antes de instalar, tenha:

- Um dispositivo Android.
- Aplicativo Termux.
- Conexão com a internet.
- Uma conta do WhatsApp.
- Git.
- Node.js.
- Python.
- FFmpeg.

> Recomenda-se utilizar uma versão atualizada do Termux obtida por uma fonte confiável.
