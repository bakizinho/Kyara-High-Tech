# Menus BKkyara

O código real dos menus está agrupado por função. Os arquivos antigos no primeiro nível são pontes de compatibilidade para preservar imports existentes.

- **principal/** — menu principal.
- **downloads/** — downloads e mídia.
- **administracao/** — administração e painel do dono.
- **criacao/** — logos, edits e figurinhas.
- **efeitos/** — alteradores de voz, texto e efeitos.
- **ferramentas/** — ferramentas e utilitários.
- **jogos/** — brincadeiras e RPG.
- **jogos/legado/** — versão legada de brincadeiras.
- **comunidade/** — membros, VIP e rankings.
- **sistema/** — modos normal/interativo e configuração.

O loader index.js permanece nesta pasta.
